# Atelier Ironwood | Bespoke Architectural Cabinetry & Millwork

A high-converting showcase portfolio website engineered for custom cabinetry shops, heirloom millwork studios, and architectural woodworkers.

## Highlights & Features
- **Visual Aesthetic:** Rich espresso walnut tones, natural travertine backgrounds, Playfair Display serif headers, and brushed champagne brass accents.
- **Interactive Joinery Anatomy Explorer:** Clickable numbered hotspots on cabinet construction highlighting English dovetail solid maple drawers, Blum Movento concealed soft-close runners, blind mortise-and-tenon face frames, and integrated warm 2700K LED reveal channels.
- **Interactive Cabinet Studio Configurator & Pricing Engine:** Real-time scope builder adjusting by space (Chef's Kitchen, Dressing Suite, Architectural Library), linear footage run (10 to 65+ linear ft), and solid hardwood species (Quarter-sawn White Oak, American Black Walnut, Hard Sugar Maple).
- **Conversion Architecture:**
  - Trust credentials: Blum Preferred Guild, AIA Partner, 100% Solid Hardwoods with Lifetime Joinery Warranty.
  - Bento grid showcasing full architectural kitchens, built-in libraries, walk-in dressing suites, and floating vanities.
  - Case studies with quantified linear footage and hardware specs.
  - 4-phase guild workflow: 3D laser spatial scan, lumber selection, workshop joinery, and in-house white-glove installation.
  - Interactive FAQ accordion addressing modular vs. custom differences, lead times, moisture acclimation, and appliance integration.
  - Private showroom appointment modal with integrated lead capture.
- **Tech Stack:**
  - HTML5 & Semantic Elements
  - Tailwind CSS via CDN
  - Lucide Icons
  - Google Fonts (Playfair Display & Plus Jakarta Sans)
  - 100% Mobile Responsive with zero build-step dependencies

## Setup & Deployment
Open `index.html` directly in any web browser or deploy immediately to GitHub Pages, Netlify, or Vercel:

```bash
# Push to GitHub
git remote add origin https://github.com/YOUR_USERNAME/atelier-ironwood-cabinetry.git
git branch -M main
git push -u origin main
```
